# Работа агентов с ViArticles

## Назначение

ViArticles — одно Go-приложение для ручного сохранения ссылок и приёма ссылок через
Telegram-бота. UI строится стандартным `html/template`, HTMX используется только как
progressive enhancement, данные хранятся в SQLite.

## Архитектура

- `cmd/viarticles` — composition root, сигналы и HTTP-сервер;
- `internal/config` — чтение переменных окружения;
- `internal/storage` — SQLite-схема и все запросы;
- `internal/telegram` — long polling Telegram Bot API;
- `internal/webapp` — HTTP-обработчики и встроенные HTML-шаблоны.

Не возвращайте PostgreSQL, Vue/Node, VK, Habr или отдельный REST API без явного запроса
пользователя. Сохраняйте модель одного бинарника и одного SQLite-файла.

## Правила разработки

1. Перед изменением выполните `git status --short` и сохраните чужие изменения.
2. Для HTML используйте стандартные шаблоны; любая операция обязана работать обычной
   HTML-формой без JavaScript, HTMX лишь обновляет фрагмент страницы.
3. Изменения схемы SQLite должны быть совместимы с уже созданной базой. После первой
   версии добавляйте явные последовательные миграции, не меняйте данные разрушительно.
4. Telegram `source_id` должен быть стабильным и уникальным; offset хранится в
   `app_state`, чтобы сообщения не обрабатывались повторно после перезапуска.
5. Не логируйте токен бота, содержимое `.env` или приватные сообщения.
